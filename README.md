# java-racingcar-precourse

# 기능 목록

## 입력 기능
- [x] 자동차 이름 입력받기
- [x] 시도 횟수 입력받기
- [x] 입력값 검증
    - 자동차 이름이 5자를 초과하는 경우 예외 처리
    - 자동차 이름이 비어있는 경우 예외 처리
    - 시도 횟수가 숫자가 아닌 경우 예외 처리
    - 시도 횟수가 양수가 아닌 경우 예외 처리

## 자동차 기능
- [x] 자동차 이름 저장
- [x] 자동차 위치 저장
- [x] 무작위 값에 따라 전진 또는 정지
    - 0~9 사이 무작위 값이 4 이상이면 전진
    - 4 미만이면 정지
- [x] 현재 위치 반환

## 경주 진행 기능
- [x] 여러 대의 자동차로 경주 진행
- [x] 각 라운드마다 모든 자동차 이동
- [x] 각 라운드 결과 출력

## 우승자 판정 기능
- [x] 가장 많이 이동한 자동차 찾기
- [x] 우승자가 여러 명인 경우 모두 찾기
- [x] 우승자 출력
